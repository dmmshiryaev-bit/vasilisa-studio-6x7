## Обновление из локальной рабочей папки

Если используется существующая локальная папка `.deploy`, сначала скопируйте изменённые игровые файлы в `.deploy` и нужные изображения в `.deploy/img`, затем из `.deploy` выполните:

    vercel deploy --prod --yes --scope dmmshiryev-8623

Связь с проектом хранится в .deploy/.vercel. Не публикуйте .env.local: это локальный файл, созданный Vercel CLI, и он уже исключён через .gitignore.

## Публикация после клонирования GitHub

Репозиторий: https://github.com/dmmshiryaev-bit/vasilisa-studio-6x7.
Папка `.deploy` и локальные данные Vercel в GitHub не включены. После клонирования можно публиковать прямо из корня репозитория: `vercel.json` задаёт статическую публикацию, а `.vercelignore` исключает документацию, скриншоты и локальные материалы.

Для владельца существующего проекта:

    vercel login
    vercel link --project vasilisa-studio-6x7 --scope dmmshiryev-8623
    vercel deploy --prod --scope dmmshiryev-8623

Для публикации в другом аккаунте выполните `vercel` и выберите собственный проект. Привязка GitHub к автоматическому деплою в Vercel в рамках этой публикации не настраивалась.

Проверено: публичная главная страница, загрузка обоих изображений, запуск математического задания. Иллюстрация отображается целиком на узком экране.
