# Установка игры

[Выбрать устройство](https://vasilisa-studio-6x7.vercel.app/install.html) · [Установочные файлы](https://yadi.sk/d/4Sm2JcVG9pg8nw)

## Windows

Скачайте `Vasilisa-Setup-0.2.0.exe`, запустите и выберите папку установки. Создаются ярлыки на рабочем столе и в меню «Пуск». Установка рассчитана на Windows 10/11 x64 и не требует постоянного интернета. Установщик не имеет коммерческой цифровой подписи издателя.

## Android

Скачайте `Vasilisa-Android-0.2.0.apk` и откройте файл. Для установки вне магазина Android может попросить разрешение выбранному браузеру или файловому менеджеру. Минимальная версия — Android 7.0.

Это первая сборка с подписью разработки, не публикация в Google Play. Для будущих обновлений с сохранением приложения понадобится постоянный ключ подписи; пока не удаляйте установленную игру без необходимости — удаление удалит и прогресс.

## iPhone и iPad

Откройте игру в Safari → «Поделиться» → «На экран Домой» → «Добавить». После первого открытия дождитесь сообщения «Игра сохранена для занятий без интернета». Отдельный IPA-файл не создаётся: используется устанавливаемая веб-версия.

## Установка через браузер

На Android и компьютере Chrome/Edge также поддерживают установку веб-приложения. Откройте страницу выбора устройства или пункт «Установить приложение» в меню браузера. После подготовки кеша игра работает без сети.

## Музыка и результаты

Задания и изображения включены в установочные файлы; встроенный ритм работает офлайн. Оригинальная песня в Spotify-плеере требует интернет и не включена в установщик. В разделе «Для взрослого» можно выбрать свой аудиофайл: он сохраняется локально в IndexedDB и после перезапуска доступен без сети. Игра не отправляет выбранную музыку на сервер.

Установленная игра и браузерная версия хранят прогресс раздельно. На новом устройстве игра начинается заново. Очистка данных браузера/приложения или удаление приложения удаляет локальный прогресс и выбранную музыку.

## Сборка для разработчика

Node.js 22+, `npm ci`, затем:

- Windows: `npm run build:windows` — результат в `dist`.
- Android: `npm run prepare:app`, `npx cap add android`, `node scripts/prepare-android.cjs`, `npx cap sync android`, затем `android/gradlew assembleDebug`. Нужны JDK 21 и Android SDK.
- GitHub Actions: workflow `Build installers` собирает оба файла на отдельных Windows/Ubuntu машинах. Исходные фотографии и локальные файлы доступа в сборку не входят.

Установочные файлы не добавляются в историю Git; они хранятся отдельно на Яндекс Диске в папке «игры для детей».
