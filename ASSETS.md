# Графика и музыка

- `img/vasilisa-toy-avatar.png` — игрушечный аватар, созданный встроенным imagegen по фотографиям, предоставленным владельцем проекта. Исходные личные фотографии остаются локально.
- `img/friends-v2.png` — дракон Искорка, фея Люми, игрушечный Газан с камерой и Василиса с микрофоном. Создано и отредактировано встроенным imagegen. Референс образа Gazan — [публичный портрет на странице артиста Spotify](https://open.spotify.com/artist/4Qdtzv8titXp66B9nwAstz).
- `img/screenshots/` — снимки [работающей игры](https://vasilisa-studio-6x7.vercel.app/).

Gazan показан в виде неофициальной сказочной стилизации. Проект не заявляет о сотрудничестве с артистом; его голос не синтезируется.

Музыкальная тема — [Gazan «67 (Six Seven)»](https://music.apple.com/us/song/1876200514). Используется официальный [Spotify-плеер](https://open.spotify.com/embed/track/7wdSCi9346RbeHjFsB6TFX), фонограмма не скопирована в проект. Игровой ритм и короткий сигнал ответа создаются программно через Web Audio API.

Шрифт Nunito загружается из Google Fonts; при отсутствии сети используется системный шрифт.

Публикация исходников сама по себе не устанавливает открытую лицензию на код, персональные изображения или материалы третьих лиц. Файл открытой лицензии в этой версии не добавлен.
